# User Stories - Microservice Account

## Format
**En tant que** [rôle]  
**Je veux** [action]  
**Afin de** [bénéfice]

---

## User Stories

### US-01 : En tant que développeur
**Je veux** configurer l'environnement de développement  
**Afin de** pouvoir exécuter le service localement

### US-02 : En tant qu'utilisateur
**Je veux** lire un compte depuis le service  
**Afin de** consulter mes informations

### US-03 : En tant qu'administrateur
**Je veux** lister tous les comptes dans le service  
**Afin de** gérer les utilisateurs

### US-04 : En tant qu'utilisateur
**Je veux** mettre à jour un compte dans le service  
**Afin de** modifier mes informations personnelles

### US-05 : En tant qu'administrateur
**Je veux** supprimer un compte du service  
**Afin de** retirer des utilisateurs invalides

### US-06 : En tant qu'équipe DevOps
**Je veux** automatiser les vérifications d'intégration continue  
**Afin de** garantir la qualité du code

### US-07 : En tant que security engineer
**Je veux** ajouter des en-têtes de sécurité et politiques CORS  
**Afin de** sécuriser l'API

### US-08 : En tant que développeur
**Je veux** containeriser le microservice avec Docker  
**Afin de** faciliter le déploiement

### US-09 : En tant que DevOps
**Je veux** déployer l'image Docker sur Kubernetes  
**Afin de** orchestrer le service

### US-10 : En tant qu'équipe
**Je veux** créer un pipeline CD pour automatiser le déploiement  
**Afin de** livrer plus rapidement
